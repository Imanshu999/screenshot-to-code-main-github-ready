# FREE / SELF-HOSTED MODE

This build is intended to run without an in-app subscription, premium tier, checkout, or credit system.

## What is free
- The application UI and self-hosted code are free to use.
- There is no in-app purchase flow or premium unlock in this build.
- You can use an OpenAI-compatible local endpoint (for example Ollama or LM Studio) through the OpenAI Base URL setting to avoid paying an AI API provider.

## Important
The application cannot make a third-party AI provider free. OpenAI, Anthropic, Gemini, ScreenshotOne, Replicate, and similar hosted services can still charge according to their own accounts and pricing. Removing a paywall from this application does not bypass those providers' billing.

For a genuinely zero-API-cost setup, run a compatible model locally and point **OpenAI Base URL** at the local server.
