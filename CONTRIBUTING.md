# Contributing

Thanks for contributing!

## Development

1. Fork or clone the repository.
2. Copy `backend/.env.example` to `backend/.env` and add your own provider credentials if needed.
3. Install frontend dependencies with `pnpm install` in `frontend/`.
4. Install backend dependencies with Poetry in `backend/`.
5. Run the frontend and backend using the commands in `README.md`.

## Pull requests

- Keep changes focused and documented.
- Do not commit API keys, tokens, passwords, or private configuration.
- Run the relevant tests before opening a pull request.
